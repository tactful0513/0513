# 🌸 K-뷰티 퍼스널컬러 · 메이크업 추천 앱

중·고등학생 **메이크업 수업**에서 쓸 수 있는 웹앱입니다.
학생이 셀카를 올리면 피부색(언더톤·밝기)을 분석해 어울리는 **한국 메이크업 스타일**을 추천해 줍니다.

## ✨ 특징

- **개인정보 안전** — 사진은 인터넷으로 전송되지 않고 **브라우저(이 기기) 안에서만** 분석됩니다. 서버·업로드·저장 없음.
- **가상 메이크업 입히기** — 추천 컬러를 실제 셀카의 입술·볼·눈 위치에 얹은 **보정 사진**을 만들어 원본과 비교하고 저장할 수 있어요. (얼굴 인식: MediaPipe FaceMesh)
- **교육용 구성** — 결과 화면에 "왜 이렇게 나왔는지"를 설명하는 학습용 해설(퍼스널컬러·Lab 색공간)이 포함됩니다.
- **수업 친화적** — 자연스럽고 학교에서도 부담 없는 데일리 메이크업 위주로 추천합니다.

> 📶 **인터넷 참고**: 퍼스널컬러 분석과 추천은 오프라인에서도 되지만, **가상 메이크업 입히기**는 얼굴 인식 라이브러리(MediaPipe)를 처음 한 번 내려받아야 해서 인터넷 연결이 필요합니다. 이때도 **사진 자체는 전송되지 않고** 기기 안에서만 처리돼요.

## 🚀 사용 방법

### 방법 1) 파일로 바로 열기 (사진 업로드만 사용)
`index.html`을 더블클릭해 브라우저로 엽니다. **사진 올리기** 기능이 바로 동작합니다.
> ⚠️ 카메라 촬영(getUserMedia)은 보안 컨텍스트가 필요해서 `file://`에서는 동작하지 않습니다.

### 방법 2) 로컬 서버로 열기 (카메라 촬영까지 사용, 권장)
```bash
# Python이 있으면
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```
`localhost` 또는 `https`에서 열면 **카메라로 찍기**까지 사용할 수 있습니다.

## 🧑‍🏫 수업 활용 가이드

1. **도입** — "퍼스널컬러란?" 웜톤/쿨톤, 봄·여름·가을·겨울을 간단히 소개합니다.
2. **체험** — 학생들이 자연광(창가)에서 셀카를 찍어 각자 결과를 확인합니다.
3. **비교/토론** — 조명(노란 실내등 vs 흰 형광등)을 바꿔가며 결과가 어떻게 달라지는지 실험합니다.
   → "왜 이렇게 나왔나" 해설을 함께 읽으며 **분석 원리(색상각·ITA)**를 이야기합니다.
4. **실습** — 추천 팔레트·단계를 참고해 실제 메이크업을 따라 해 봅니다.
5. **마무리** — "퍼스널컬러는 참고일 뿐, 어떤 색이든 즐겨도 좋다"는 열린 태도를 강조합니다.

## 🔬 분석 원리 (요약)

1. 얼굴 중앙(볼·이마) 영역에서 **피부색 픽셀**만 골라 평균 색을 구합니다. (RGB + YCbCr 규칙)
2. 평균 색을 **Lab 색공간**으로 변환합니다.
3. **색상각(hue)**으로 웜/쿨(뉴트럴) 언더톤을, **ITA°**로 피부 밝기를 판정합니다.
4. 두 값을 조합해 봄웜·여름쿨·가을웜·겨울쿨 중 하나로 매핑하고 스타일을 추천합니다.

> 결과는 사진의 조명·화질에 영향을 받는 **재미·학습용 추천**입니다. 정확한 퍼스널컬러 진단은 자연광에서, 전문가와 함께가 가장 좋아요.

## 📁 파일 구조

```
index.html      # 화면 구조
css/styles.css  # 스타일 (K-뷰티 파스텔 테마)
js/data.js      # 4계절별 메이크업 추천 데이터
js/app.js       # 사진 입력 + 피부색 분석 + 결과 렌더링
```

## 🔒 개인정보 안내 (미성년자 대상)

- 이 앱은 사진을 **어디에도 업로드/저장하지 않습니다.** 모든 처리는 학생 기기의 브라우저 메모리에서만 이뤄지고, 페이지를 닫으면 사라집니다.
- 학교에서 사용할 때도 학생의 얼굴 사진이 외부로 나가지 않으므로 안심하고 활용할 수 있습니다.
